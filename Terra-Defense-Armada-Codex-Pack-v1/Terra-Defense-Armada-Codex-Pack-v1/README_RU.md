# Страж Терры: Армада - пакет для Codex v1

English: **Terra Defense: Armada**.

12 ноября 2026 года. Единое задание на первый браузерный прототип.

## Как передать в Codex

1. Распаковать этот архив рядом с проектом или в отдельную рабочую папку.
2. Открыть папку проекта в VS Code / Codex и дать доступ к распакованному пакету.
3. Вставить целиком текст `CODEX_PROMPT_EN.md`. Он задаёт порядок реализации и проверки.
4. Для чтения правил человеком открыть `docs/Strazh-Terry-Armada-Spec-RU-v1.pdf` или `docs/SPEC_RU.md`.

## Состав

| Файл | Назначение |
| --- | --- |
| CODEX_PROMPT_EN.md | Полное задание разработчику на английском |
| docs/SPEC_RU.md | Единое ТЗ, полные правила и референсы |
| docs/Strazh-Terry-Armada-Spec-RU-v1.pdf | Оформленная версия того же ТЗ |
| docs/BRANDING_RU.md | Утверждённые названия RU/EN и их использование |
| docs/IMPLEMENTATION_PLAN_RU.md | Этапы и условия готовности |
| docs/ACCEPTANCE_RU.md | Сценарии приёмки с ожидаемым поведением |
| docs/ART_BRIEF_RU.md | Подготовка восьми отдельных игровых спрайтов |
| docs/DECISIONS_RU.md | Последние решения, отменённые варианты, предварительные значения |
| config/game_rules.json | Принятые константы и явно помеченные допущения |
| config/branding.json | Точные названия для русского и английского интерфейсов |
| config/balance_draft.json | Предварительные параметры ботов и чистого профиля |
| config/challenges.json | Пять сценариев, лимиты, счётчики, стартовые наборы |
| assets/references/ | Финальный флот и два компактных HUD |
| assets/space_battle_nicknames_500.json | 500 утверждённых RU/EN никнеймов |
| assets/asset_manifest.json | Источники и список ещё необходимых спрайтов |
| sources.json | Происхождение материалов и ссылки на SDK |
| MANIFEST.sha256 | Контрольные суммы всех файлов пакета, кроме самого манифеста |

Приняты: три режима и пять испытаний; четыре способности; локальные честные боты; Скорпион вместо Шторма; компактный HUD; по одному сохранению на режим; реванш с тем же ботом и новой расстановкой.

Предварительные значения отмечены прямо в JSON и ТЗ. Пакет не содержит готового игрового кода и отдельных прозрачных спрайтов. Обозначение v1 относится к пакету документов, а не к выпущенной версии игры. Игровые тесты и баланс будут проверяться после реализации.
