# Задание на игровые изображения

## Что уже утверждено

Название RU: **Страж Терры: Армада**. Название EN: **Terra Defense: Armada**. В шапках исходных референсов ещё встречается рабочее название «Космический бой». Сохранить эти оригиналы как источники дизайна; в игровом интерфейсе заголовок отрисовывается отдельно по `config/branding.json`.

`assets/references/fleet_final.png` - окончательный общий лист восьми моделей. HUD-референсы задают оформление экранов, но не правила расстановки: флот на них показан условно.

## Что подготовить

Восемь самостоятельных PNG с прозрачным фоном по именам в `assets/asset_manifest.json`. Строгий вид сверху; без текста, рамок, координат, клеток и космического фона. Образ каждой модели сохранить по финальному листу. Старые концепты не использовать для отмены правок.

| ID файла | Название | Полоса клеток |
| --- | --- | --- |
| hero_prototype.png | Прототип | 1 x 1 |
| hero_twin.png | Близнец | 2 x 1 |
| hero_bastion.png | Бастион | 3 x 1 |
| hero_monolith.png | Монолит | 4 x 1 |
| enemy_standard.png | Обычный | 1 x 1 |
| enemy_scorpion.png | Скорпион | 2 x 1 |
| enemy_cascade.png | Каскад | 3 x 1 |
| enemy_hammer.png | Молот | 4 x 1 |

Инженерный контракт экспорта: нос вправо, альфа-фон, центральная ось по середине высоты; холст соотношения length:1. Рекомендуемый исходный размер 256 px на клетку: 256x256, 512x256, 768x256, 1024x256. Это производственный размер, не обязательное разрешение игры. Подгонять модели пропорционально, без растяжения рисунка; если исходный силуэт не помещается, адаптировать детали, сохранив узнаваемость. Проверять и при малых клетках 20-32 CSS px.

Финальный лист содержит художественные неточности сетки. Фактическая полоса спрайта должна соответствовать точному числу квадратных клеток. При подготовке брать корабль целиком, не вырезать только отдельную секцию.

## Обязательные особенности

- Прототип: белая/серая броня, оранжевые акценты, голубое свечение; узнаваемый принятый корабль героя.
- Близнец: два массивных двигателя, на них сверху пушки у заднего основания; сзади кабина на кабелях. Кабину и двигатели ориентировать согласованно. Строгий верхний ракурс, пушки как верхние установки Бастиона/Монолита.
- Бастион и Монолит: верхние башни, формы и пропорции финального листа.
- Обычный: клешнеобразный раздвоенный силуэт, оливковая броня.
- Скорпион: сохранённые передние орудия; низкая кормовая башня, один ствол вперёд к носу; без удалённых задних крыльев. Это адаптация для Космического боя, не новая расширенная 2.5D-модель из Terra Defense.
- Каскад: ракетные кассеты сдвинуты к кабине.
- Молот: массивный ударный нос и длинный тяжёлый корпус.

Попадания/цели/уничтожение/окружение рисовать отдельным слоем интерфейса. Для уничтожения использовать серый силуэт и перечёркивание. Не запекать повреждения в базовый спрайт. Логическая геометрия корабля состоит из клеток, прозрачные края рисунка не меняют правила.

## Проверка перед подключением

1. Альфа без фона, сетки и подписи; нет обрезанных орудий, кабелей или носа.
2. Нос вправо, корректный поворот на вертикальное размещение.
3. Силуэт занимает только свою полосу; не заходит в соседние клетки.
4. Отдельно читаются классы на малом поле; попадания поверх модели различимы.
5. Все восемь файлов отмечены готовыми только после визуального сравнения с референсом.

Состояние в этом пакете: референсы включены, производственные PNG ещё не созданы. Если они временно заменены простыми формами, это явно указывается в отчёте о прототипе.
