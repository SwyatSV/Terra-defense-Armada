# План реализации

Все этапы ведут к одной версии с тремя режимами и пятью испытаниями.

| Этап | Работы | Условие готовности |
| --- | --- | --- |
| 0. Подготовка | Прочитать инструкции репозитория, пакет и конфиги. Зафиксировать стек и допущения. | Есть команда локального запуска и проверок, понятен статус ассетов. |
| 1. Классика | Ядро поля, флот, расстановка, генерация бота, поиск/добивание, очередь, попадания, окружение, результат, реванш. | Полную партию можно сыграть до конца мышью и касаниями; бот честный. |
| 2. Сохранения | Три фиксированных слота, профиль, меню, авто/ручное сохранение, подтверждение замены, настройки. | Восстанавливаются подготовка и обе очереди без повторного действия. |
| 3. Тактика | Четыре способности, подтверждения, знания, одна способность на очередь, ремонт и повторный выстрел, постоянные заряды и стартовое право. | Все переходы очереди и экономика проверены; загрузкой нельзя получить заряд. |
| 4. Испытания | Пять сценариев, лимиты, наборы, выбор шести зарядов, рекламное ожидание/продолжение, отметки. | Победа последним ресурсом, изоляция запасов и единственное пополнение проверены. |
| 5. Интеграция | Локальный/реальный платформенный адаптер, SDK, пауза, финальная графика, RU/EN, компактный HUD. | Firefox и мобильные размеры пройдены; реальная награда подтверждается только платформой. |
| 6. Баланс | Прогоны с фиксированными наборами условий и плейтест. Отчёт по победам, длительности, расходу зарядов и лимитам. | Есть реальные измерения и список предлагаемых правок; подтверждённые правила сохранены. |

На каждом этапе держать игру запускаемой. Для игровых правил и транзакций нужны содержательные тесты; не писать проверки, просто повторяющие разметку кнопок. Не заявлять готовность SDK после одного локального mock-показа. Если производственные спрайты ещё не готовы, явно указать это в отчёте, сохранив возможность тестировать ядро.

Первый браузерный прототип проверять в Firefox. Промежуточная EXE-сборка в задание не включена. Перед внешней публикацией подготовить проверяемую сборку и отчёт; сам этот пакет ничего не публикует.
