# Решения и статус параметров

Дата пакета: 12.11.2026. Последние прямые решения пользователя имеют приоритет.

## Действующие решения

Официальное название RU: **Страж Терры: Армада**. EN: **Terra Defense: Armada**. Короткое название: Армада / Armada. Это последняя утверждённая пара названий. Прежнее рабочее имя «Космический бой» в интерфейсе заменяется; игровые правила остаются прежними.

| Тема | Текущее решение | Отменённый вариант |
| --- | --- | --- |
| Сохранения | По одному на режим; один общий слот всех испытаний | Много партий, названия, список с удалением |
| Противник | Локальный случайный честный бот | Сервер, онлайн-комнаты, нечестный бот |
| Набор способностей | Импульс, наведение, двойной залп, ремонт | Кассетный удар, щит |
| Лимит способности | Одна за всю очередь, попадания не обновляют | Новый лимит после каждого попадания |
| Флот | Прототип/Близнец/Бастион/Монолит и Обычный/Скорпион/Каскад/Молот | Старые предложенные имена героя |
| Скорпион | Кормовая одноствольная башня; принятый общий лист | Название Шторм, удалённые задние крылья |
| Близнец | Строго сверху; пушки у задних оснований моторов | Перспективный рисунок, прежнее положение пушек |
| Каскад | Ракеты ближе к кабине | Прежнее заднее положение ракетных блоков |
| HUD | Компактные кнопки, поля крупнее, клетки квадратные | Старые большие блоки «Огонь» и способностей |

| Охота на флагман | 35 действий, однократно +8 за рекламу | Ранние 30/40 действий |
| Дефицит боеприпасов | 45 боеприпасов | 65 на старте |
| Бесплатный заряд | На старте при открытом праве; после сдачи следующий бой без начисления | Начислять и на старте, и на завершении; фарм перезапусками |
| Реванш | Тот же профиль бота, новые расстановки обеих сторон | Повтор прежнего скрытого расположения |

## Предварительный баланс

- Доли уровней бота 30/40/25/5; характеры равновероятны.
- Стартовые наборы бота по характеру и все стартовые наборы испытаний.
- У дефицита рекламная прибавка +10; у ошибок повышение лимита до 45.
- Профили ботов в конкретных испытаниях, в том числе средний агрессивный для Последнего рубежа и экспертный сбалансированный для Превосходства интеллекта.
- Добровольное единственное пополнение одной способности в двух испытаниях без лимита: импульс +2, остальные +1.
- Рабочая схема отметок: Пройдено с пополнением / Мастерство без него. Сохранять лучший результат.

## Инженерные допущения прототипа

Это конкретные значения для неблокирующих пробелов, а не новые утверждения от пользователя:

- Первый ход 50/50; бросок один раз на старте.
- Чистый профиль: 0 зарядов, право на первый стартовый +1 открыто; четыре типа +1 равновероятны.
- Начальные направления размещения: вправо/вниз, поворот вокруг носовой клетки.
- Импульс всегда полного размера 3x3 внутри поля, у края сдвигается внутрь; результат хранится как снимок.
- Наведение выбирает целую ещё неизвестную секцию и недоступно, когда таких нет.
- Ремонт виден обеим сторонам в восстановленной клетке; ранее известное положение не забывается.
- Во флагмане наведение/ремонт стоят по 1 действию, импульс 0; залп 1. В боезапасе залп стоит 2, обычный выстрел 1, прочие 0.
- Для трёх лимитных испытаний профиль бота по умолчанию средний сбалансированный.
- Выбор локального хранилища и TypeScript-стека оставлен разработчику, важны атомарность и поведение.

## Материалы и предел готовности

Общий флот и HUD приняты как концепты. Восемь прозрачных игровых спрайтов ещё необходимо подготовить. Проверка сборки игры, поведения ботов и измерение баланса выполняются после реализации; этот пакет не подменяет их отчётом о документах.
