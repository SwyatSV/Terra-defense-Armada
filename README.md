# Страж Терры: Армада / Terra Defense: Armada

Браузерный прототип v0.1.0 по приложенному пакету ТЗ. Разработка ведётся в ветке `v0.1.0-terra-defense-armada`. Исходный пакет сохранён без изменения; `main` не используется для разработки.

## Запуск

Нужен Node.js 24 или новее. В PowerShell используйте `npm.cmd`, если выполнение `npm.ps1` запрещено политикой системы.

```powershell
npm.cmd ci
npm.cmd run dev
```

Открыть **http://127.0.0.1:5173**. Это локальная одиночная игра; сервер матчей и аккаунт не нужны. Открытие `index.html` двойным щелчком не заменяет запуск сервера модулей.

```powershell
npm.cmd run build
npm.cmd run preview
```

Сборка находится в `dist/`; предварительный просмотр — http://127.0.0.1:4173. Для внешнего размещения передать содержимое `dist/` статическому хостингу. Публикация не выполнялась.

## Что реализовано

- Классический и тактический бой, все пять испытаний из конфигурации.
- Выбор флота, ручная расстановка с предварительным просмотром, перемещение, поворот, удаление, отмена, случайная расстановка и очистка.
- Полные партии с локальным ботом, попаданиями, добиванием, окружением, результатом и реваншем. Четыре скрытых сложности и характера; исходный словарь 500 имён сохранён.
- Импульс, наведение, атомарный двойной залп, ремонт живого корабля. Одна способность на всю очередь.
- Постоянный тактический инвентарь, право стартового начисления, отдельные запасы испытаний, лимиты, однократное продолжение и лучшие отметки.
- Три фиксированных слота, автосохранение подготовки и принятых действий, ручное сохранение в паузе, подтверждение замены.
- RU/EN, настройки звука, синтезированные музыка/эффекты, сокращение анимаций, управление мышью и касаниями.
- Восемь отдельных прозрачных изображений в `public/assets/sprites/`; два квадратных поля с адаптацией к ориентации и высоте окна.
- Отдельный платформенный адаптер, пауза SDK/рекламы/скрытой вкладки, тестовые исходы рекламы.

Расстановка: выберите класс корабля, затем клетку **носа** и подтвердите. При направлении вправо корпус продолжается от носа влево; при направлении вниз — вверх. Нажатие на установленный корабль начинает редактирование, исходное положение сохраняется до подтверждения. Для выстрела сначала выберите клетку, затем нажмите «Огонь».

## Сохранения и реклама

Рабочий профиль хранится в `localStorage["armada.v1"]`. Профиль и три режимных снимка записываются одним атомарным `setItem`, после завершения обработки команды. Инвентарь профиля не восстанавливается из режима. Повторные награды защищены идентификатором операции. Устаревшая вкладка не может перезаписать обнаруженное более новое сохранение; при ошибке записи действие не принимается в память приложения. Повреждённый или неподдерживаемый файл не перезаписывается автоматически.

По адресу **http://127.0.0.1:5173/?devAds=1** используется отдельный профиль `armada.v1.test`. Кнопка пополнения позволяет выбрать `success`, `cancel`, `error` или `unavailable`. Тестовый успех не выдаёт награды рабочему профилю. Без SDK в обычном режиме реклама недоступна.

Для среды Яндекс Игр включить `?platform=yandex` при запуске — загрузчик `/sdk.js`; для собственного домена `?platform=yandex-custom` — официальный абсолютный URL загрузчика. На localhost без прокси загрузчик Яндекса не предоставляется. Реальный запуск, модерация и реальные рекламные показы в консоли платформы ещё не проверены. Ссылки и проверенный контракт: [docs/SDK_NOTES.md](docs/SDK_NOTES.md).

## Структура

- `src/engine.ts` — правила, транзакции, экономика, снимок знаний и решения бота, без DOM/SDK.
- `src/main.ts` — экраны и обработка ввода; `src/storage.ts` — сохранения.
- `src/platform.ts`, `src/audio.ts` — платформа и звук.
- `src/data.ts` — использование исходных JSON без изменения принятых параметров.
- `tests/` — правила и проверки браузеров; `scripts/benchmark.ts` — воспроизводимая проверка стратегий.
- `public/assets/sprites/` — игровые PNG. [Промпты и статус графики](docs/ART_GENERATION.md).

Это прототип для проверки игры. Финальная художественная приёмка и реальная платформенная приёмка остаются отдельными работами; подробности указаны в отчёте.
